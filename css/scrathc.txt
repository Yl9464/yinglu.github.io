Why I recommend this

For a personal site, simplicity is actually an advantage. You don't need hundreds of CSS classes or a complicated component system.

I'd aim for:

HTML
→ semantic structure

CSS
→ layout + colors + typography + responsiveness

JavaScript
→ only when you actually need interaction

For example:

<header>
    <nav>...</nav>
</header>

<main>
    <section id="about">...</section>
    <section id="projects">...</section>
    <section id="skills">...</section>
    <section id="contact">...</section>
</main>

<footer>...</footer>
For your portfolio specifically

Since you're building toward CS/cybersecurity roles, I'd lean toward a minimal professional developer portfolio rather than a heavily animated "designer" website.

Something like:

Ying Lu
Computer Science Student | Cybersecurity & Digital Forensics

About · Projects · Skills · Resume · Contact

Then have project cards for things like your AI Movie Assistant, coursework/projects, and cybersecurity work.

A dark theme with subtle blue/green accents would also fit cybersecurity well without looking overly "hacker themed."
